# 🏆 Stadium Defense - Sportovní Tower Defense

Moderní, svižná a vizuálně poutavá Tower Defense hra v prohlížeči (HTML5 Canvas + čistý moderní JavaScript & CSS) se sportovní tématikou.

## 🎮 O hře
Chraňte Zlatý pohár v Síni slávy před invazí divokých fanoušků, maskotů a výtržníků! Rozmisťujte elitní sportovce podél atletického oválu, vylepšujte jejich schopnosti a odrazte všech 15 vln soupeřova kotle.

### 👥 Sportovci (Věže)
- 🎾 **Tenista (100 🎟️):** Vysoká kadence útoků. Skvělý na eliminaci rychlých běžců. Vylepšení přidává kritický *esový servis*.
- 🏒 **Hokejista (140 🎟️):** Ledové puky zpomalující útočníky o 55 %. Vylepšení přináší plošnou mrazivou explozi.
- 🏀 **Basketbalista (175 🎟️):** Slam dunk obloukem s plošným dopadem (Splash AoE).
- ⚽ **Fotbalista (195 🎟️):** Dělovka, která prorazí více útočníků v řadě s lehkým odmrštěním.
- 🎯 **Oštěpař (225 🎟️):** Olympijský snajpr s obřím dostřelem. Proráží brnění chuligánů.

### 🏃 Nepřátelé
- **Běžný fanoušek:** Vyvážený útočník.
- **Streaker (Naháč):** Extrémně rychlý běžec.
- **Klubový maskot:** Plyšový tank odolný vůči zpomalení.
- **Kotelník (Hooligan):** Obrněný výtržník s dýmovnicí.
- **Šéf kotle (Boss):** Vůdce se zlatou korunou a fázemi sprintu.

## 🕹️ Ovládání
| Klávesa / Akce | Funkce |
| :--- | :--- |
| `1` - `5` | Výběr sportovce |
| `Kliknutí` | Postavení věže / výběr sportovce |
| `Kliknutí na vybraného` | Okamžité vylepšení (Upgrade) |
| `U` | Vylepšení vybraného sportovce |
| `S` | Prodej vybraného sportovce (70 % refundace) |
| `N` | Spuštění další vlny |
| `Mezerník` | Pozastavení hry (Pauza) |
| `Esc` | Zrušení výběru / stavebního režimu |
| `1x / 2x` | Přepínání rychlosti hry |

## 🚀 Spuštění
Otevřete `index.html` v libovolném webovém prohlížeči, nebo spusťte lokální server:
```bash
python -m http.server 8000
```
a v prohlížeči přejděte na adresu `http://localhost:8000`.
